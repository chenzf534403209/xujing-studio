# 续镜 · AI 短剧制作台

![续镜宣传图。2 个实际剪点锚点、6 项连续性检查，返修 1 镜后复核相邻 2 个剪点。](assets/xujing-promo.png)

续镜是一款面向多集 AI 短剧的 Windows 工作台。创作者可以按集编排分镜，调用本地 MiniMax H3，并沿实际剪辑时间线接拍、换版和验收。

- **按实际剪点续拍。** 选择双端接拍时，可用上一镜实际末帧和下一镜实际入点约束中间镜头。提交前可查两端的采用版本和帧号。
- **生成前核对六项连续性。** 本机模型对照上一镜实际末帧与本镜开场，逐项检查站位、视线、左右手、道具和光线。冲突和看不清的地方会单独提示，由制作者确认。
- **只重做有问题的镜头。** 在三段连播中把问题标到具体帧及验收项。换入中间镜头的新候选后，复核左右两个剪点，还可追查下一镜是否用了旧版片尾。

## 和市面工具放在一起看

| 制作场景 | 市面产品的公开能力 | 短剧制作台的做法 |
| --- | --- | --- |
| 长剧情拆镜 | **可灵 4.0** 单次原生生成最长 **30 秒**，支持最多 **15 个参考素材**、最多 **10 个关键帧输入**。 [可灵 4.0 官方发布说明](https://ir.kuaishou.com/news-releases/news-release-details/kling-ai-officially-launches-next-generation-kling-40-raising/) | 按集管理每场、每镜的分镜、候选、采用版和入出点。目标时长、实际入剪时长和待复核剪点集中在分集工作台，点待办可直接回到对应镜头或剪点。 |
| 续拍与换剪点 | **Runway Workflows** 可抽取指定帧、首帧或末帧，并把上一段末帧接到下一次生成。 [Runway 媒体工具节点](https://help.runwayml.com/hc/en-us/articles/47184761711379-Using-Utility-Nodes-in-Workflows) | 从本集实际入剪的版本和剪点取帧，提交前可查来源。启用双端时，保存前镜出点和后镜入点这 **2 个实际锚点**。换版或改剪点后，相关旧绑定需要重核。 |
| 补拍与返修 | **LTX Desktop** 支持用两端片段补空档、重生成片段内的指定区间，并保留多个可切换的版本。 [LTX Desktop 生成指南](https://help.ltx.io/hc/en-us/articles/37088993051794-Generate-a-video-in-LTX-Desktop) | 在前、中、后三段连播里，把问题记到具体帧和分镜验收项。返修只生成本镜候选，换入中间镜头后，标记受影响的 **2 个相邻剪点**。如果下一镜仍引用旧版片尾，工作台会显示旧版依赖，由制作者决定是否重做。 |

## 验收示例

- 正式样片《露台交钥匙》保留原前后镜，本地 H3 只重做中镜。两个实际锚点分别对齐中镜 f0 和 f140，双端画面已采用。
- 三镜返修流程用模拟 H3 验证。问题定位到中镜 f37，换入通过验收的新候选后复核两个剪点，导出为原 A、新 B、原 C，共 216 帧、24 fps、9 秒。
